# NYC Taxi Trip Duration Prediction

## Project Overview

This project aims to develop a machine learning model that predicts the duration of New York City taxi trips using historical trip data.

## Problem Statement

Accurately estimating taxi trip duration can support passenger planning, estimated arrival times, and transportation operations.

## Machine Learning Approach

* **Problem type:** Supervised learning — regression
* **Dataset:** [NYC Taxi Trip Duration — Kaggle](https://www.kaggle.com/competitions/nyc-taxi-trip-duration/data)
* **Evaluation metrics:** Mean Absolute Error (MAE), Root Mean Squared Error (RMSE), and R²

## Project Goals

* Explore and prepare historical taxi-trip data.
* Develop a baseline regression model.
* Evaluate and compare model performance.
* Document the proposed ML workflow, evaluation, and monitoring strategy.

## Tools and Technologies

* Python
* Pandas and scikit-learn
* AWS (planned, subject to project requirements)
